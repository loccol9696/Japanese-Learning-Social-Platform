# Japanese Learning Social Platform

Nền tảng mạng xã hội kết hợp học tiếng Nhật: Video ngắn tương tác, Flashcard, luyện nói Shadowing và hỗ trợ tạo kịch bản từ AI.

## 🛠 Tech Stack & Kiến trúc
- **Mô hình Repository:** Monorepo (`frontend/`, `backend/`, `docs/`)
- **Frontend:** Flutter (Mobile App - Android/iOS)
- **Backend:** Spring Boot (Java 17, Spring Data JPA, Maven)
- **Database:** Microsoft SQL Server
